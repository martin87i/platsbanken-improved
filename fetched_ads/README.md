# fetched_ads

Här lägger jobbsamlaren filen `platsbanken_improved.json` med jobb från arbetsgivares egna
karriärsidor. Finns filen visar tillägget jobben under fliken Externa webbplatser i Platsbanken.

Bara den här README-filen finns i git. Allt annat i mappen ignoreras (se `.gitignore`) och tas inte
med när tillägget publiceras.
